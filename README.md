# Padel Finder Example

A full padel court booking experience in Next.js — pick a court, choose a date, grab a 90-minute slot, confirm your booking, and manage everything from user and admin views.

Demo-friendly: persistence works with localStorage so you can try the whole flow without standing up a backend.

## Who it's for

- Clubs and court operators exploring an online booking UX
- Product teams prototyping sports reservation flows
- Devs who want a complete booking UI with admin tools as a reference

## What you get

- Court listing and selection
- Calendar date picking (no past dates)
- 90-minute time slots with availability
- Booking form with validation + confirmation
- My bookings search / cancel by email
- Admin dashboard: courts, bookings calendar, stats and reports
- In-repo guides: `START_HERE.md`, `QUICK_START.md`, `ARCHITECTURE.md`, and more
- Live demo: [padel-ver.vercel.app](https://padel-ver.vercel.app)

## Try it

**Live:** [Open the demo](https://padel-ver.vercel.app)

**Local:** use the Node package manager of your choice, then run the `dev` script — `package.json` serves on port **3003**. Walk through a booking using `QUICK_START.md`.

**Containers:** build and start from the repo root with the included Compose file.

## Stack

Next.js · React · TypeScript · Tailwind · Framer Motion · shadcn/ui
